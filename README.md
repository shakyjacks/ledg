# LEDG

Live standings and scores for the LEDG fantasy football league, pulled straight from Sleeper.

- Site: https://shakyjacks.github.io/ledg/
- LEDG tiebreaks: head-to-head, then points (two teams). Three or more teams: a team that swept the others wins, a team swept by all the others is last, otherwise points. Remaining teams go through the rules again.
